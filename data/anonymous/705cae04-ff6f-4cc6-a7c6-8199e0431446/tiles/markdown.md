# Markdown Reference (standard)




## Headings
```
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
```




## Emphasis
*italic* &nbsp; **bold** &nbsp; ***bold italic*** &nbsp; ~~strikethrough~~




## Lists
Unordered:
* item
  * nested item




Ordered:
1. First
2. Second




Checkboxes (interactive todos):
- [ ] Unchecked
- [x] Checked




## Blockquote
> A quote or callout




## Code
Inline `code` and code blocks:




```
a code block
```




## Horizontal rule
Three dashes on their own line produce a divider:




---




## Links and images
[link text](https://example.com)

## Tables
Insert with a right-click, or type manually:




| Column A | Column B | Column C |
|----------|----------|----------|
| cell     | cell     | cell     |
| cell     | cell     | cell     |
| cell     | cell     | cell     |








## Line break
Add two trailing spaces at the end of a line to force a hard break  
without starting a new paragraph.
